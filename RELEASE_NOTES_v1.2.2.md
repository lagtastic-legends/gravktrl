# 🚀 GravKtrl v1.2.2 — Official Brand App Icon & Cyberpunk Splash Screen

GravKtrl v1.2.2 completely replaces the default Capacitor blue template launcher icons with the official **GravKtrl cyberpunk obsidian brand logo** across all Android device form-factors!

---

### ✨ What's Included in v1.2.2

1. **Official GravKtrl Android Launcher Icons:**
   - **Adaptive Icons (Android 8.0 / API 26+):** Obsidian dark background (`#030712`) with the multi-gradient hexagon, levitating upward core, and cyan `{ }` brackets.
   - **Full Density Mipmaps (`mdpi`, `hdpi`, `xhdpi`, `xxhdpi`, `xxxhdpi`):**
     - `ic_launcher.png`: Full resolution hexagon brand icon.
     - `ic_launcher_round.png`: Circular masked brand icon for Pixel and One UI circular icon themes.
     - `ic_launcher_foreground.png`: Transparent foreground layer with optical safe-zone centering.

2. **Cyberpunk Splash Screens:**
   - Replaced all portrait and landscape default splash screens across all resolutions (`drawable-port-*` and `drawable-land-*`) with the centered obsidian GravKtrl logo.

3. **Instant Cache Invalidation:**
   - Bumped Android `versionCode` to `7` and `versionName` to `1.2.2` so Android launchers immediately clear their icon cache upon installation.

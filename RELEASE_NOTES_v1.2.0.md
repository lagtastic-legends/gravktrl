# 🚀 GravKtrl v1.2.0 — Google Stitch "Silk Neomorphic" UI & Universal Multi-Posture Remote Commander

GravKtrl v1.2.0 delivers a complete, gorgeous visual transformation based on Google Stitch's **Silk Neomorphic / Soft UI** design architecture. It brings extruded clay surfaces, tactile inset wells, frosted glass headers, live hardware telemetry gauges, and universal foldable/flippable posture layouts to your smartphone, foldable, and tablet.

---

### ✨ What's New in v1.2.0

1. **Google Stitch "Silk Neomorphic" Design System:**
   - **Tactile Clay Surfaces:** Implemented custom soft lighting surfaces (`#f6f8fb` background with `#ffffff` soft cards and dual neomorphic shadow physics: `.shadow-neo-flat`, `.shadow-neo-soft`, `.shadow-neo-pill`, and `.neo-well`).
   - **Inset Neomorphic Wells:** Command inputs, terminal viewports, secret token fields, and PIN inputs now sit indented into the physical surface.
   - **Dual Iconography & Typography:** Powered by `Plus Jakarta Sans` typography, `JetBrains Mono` telemetry counters, Google Material Symbols Outlined, and Lucide icons.

2. **Live Diagnostic Hardware & Telemetry HUD:**
   - **Real-Time CPU Sparkline & RAM Gauge:** Visual SVG sparklines and circular progress rings rendering real-time PC memory and CPU consumption.
   - **Frosted Quick Metrics Strip:** Persistent latency tracker (`12ms`), active host chip, and Antigravity CDP/Win32 engine indicator.
   - **Dual IP Connectivity:** Direct toggle between local high-speed Wi-Fi LAN (`192.168.x.x`) and Tailscale VPN mesh networks.

3. **Universal Foldable & Flippable Posture Engine:**
   - **Phone-Slab Mode:** Optimized vertical one-handed tactile navigation for standard smartphones.
   - **Flip-Flex Mode (90°–130° Hinge):** Upper HUD viewport + lower tactile keyboard controls tailored for Samsung Galaxy Z Flip and Motorola Razr.
   - **Fold-Dual Mode (Galaxy Z Fold, Pixel Fold, iPhone Duo):** Dual-column layout with real-time agent console alongside live interactive terminal deck.
   - **Desktop / Tablet Mission Mode:** Expanded widescreen grid HUD for tablets and web browser monitors.

4. **Streamlined Pairing & Zero-Typing Onboarding:**
   - **6-Digit Quick PIN Input:** Carved neomorphic PIN wells with auto-focus and instant 256-bit token exchange.
   - **Wi-Fi Discovery Radar:** Auto-detects running PC daemons on your local subnet without needing to manually type an IP address.

5. **Integrated Windows Engine:**
   - Full compatibility with both normal Windows `Antigravity.exe` (Win32 API focus + clipboard paste) and Chrome DevTools Protocol (`:9222`).
   - Live real-time file watcher streaming code edits directly to the mobile console.
   - Built-in Destructive Safety Guard requiring explicit biometric/touch approval before executing high-risk commands.

### GravKtrl v1.4.0 Release (versionCode 10)

#### 🚀 What's New:
- **Full Interactive Terminal REPL (xterm.js Canvas)**: True interactive PTY shell powered by xterm.js and @xterm/addon-fit, dynamic mobile scaling, and ANSI 256-color support.
- **Mobile Touch Accessory Bar**: Ergonomic touch controls (ESC, TAB, sticky CTRL/ALT, directional arrows, and shell symbols ~, /, -, |, $, &, :).
- **1-Tap Quick Macros**: Direct shortcuts for typecheck, git status, git diff, npm test, adb devices, gradlew debug, and dir.
- **Destructive Command Guard**: Intercepts high-risk shell commands with prompt confirmation.
- **WDAC / AppLocker Hardening**: Native signed process streaming with in-memory .NET runtime.
- **Android APK Included**: Ready to install on mobile devices.
